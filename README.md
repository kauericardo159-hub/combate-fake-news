# 🛡️ Combate às Fake News | Anatomia da Informação

Página web informativa e responsiva desenvolvida como projeto prático do curso de Programação Web (Alura / Start). O objetivo do site é conscientizar os usuários sobre os riscos da desinformação digital e apresentar um guia prático para verificar a veracidade de notícias antes de compartilhá-las.

---

## 📋 Sobre o Projeto

Com a velocidade de compartilhamento nas redes sociais, identificar conteúdos falsos tornou-se uma habilidade essencial. Esta página apresenta o conceito de **Anatomia da Informação** e organiza um checklist visual em 4 etapas fundamentais para checagem de fatos:

1. **Verificação da Fonte e URL:** Análise da credibilidade do veículo e estrutura do endereço web.
2. **Leitura Além do Título:** Identificação de manchetes sensacionalistas (*clickbait*) e leitura do contexto completo.
3. **Checagem da Data:** Verificação temporal para evitar o compartilhamento de notícias antigas fora de contexto.
4. **Consulta a Agências de Checagem:** Validação em plataformas especializadas em *fact-checking*.

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo (`header`, `main`, `section`, `article`, `footer`).
* **CSS3:** Estilização moderna utilizando variáveis CSS (`:root`), Flexbox, CSS Grid, sombras, transições suaves e design responsivo (`@media queries`) adaptado para dispositivos móveis e desktops.
* **GitHub Pages:** Hospedagem gratuita do site estático.
